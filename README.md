# Summonable Portals Mod

Add summonable portals to your Minecraft world.

## Features

- Create summonable portals that teleport players to specific locations.
- Visual and sound effects when entering a portal.

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or later

## Installation

1. Download the mod JAR file.
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

1. Craft or obtain a Summonable Portal item.
2. Place the portal block in the desired location.
3. Step into the portal to teleport to the specified location.

## Configuration

No additional configuration is required. The mod works out of the box.
